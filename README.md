# My Matrix

A pitch-black color theme for Cursor and VS Code, inspired by the digital rain in *The Matrix* (1999):
erin green `#00FF41` family on pure black, bright red errors, and a few readable accents
(teal strings, amber numbers, cyan types). Covers the editor, terminal, sidebar, tabs,
status/title bars, popups, scrollbar and minimap.

## Install

1. Download `my-matrix-theme-1.0.0.vsix` from this repo.
2. Run `cursor --install-extension my-matrix-theme-1.0.0.vsix` (or `code --install-extension ...`).
3. Pick **My Matrix** with Ctrl+K Ctrl+T.

Font and cursor settings can't live in a theme. Copy them from
[`settings/cursor-settings.json`](settings/cursor-settings.json) into your user settings.json.
